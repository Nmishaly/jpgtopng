# המרת JPG ל-PNG

אתר web להמרת תמונות JPG (וגם HEIC של אייפון) ל-PNG בכמויות – מאות קבצים בבת אחת – עם הורדה כ-ZIP, הורדה של כל קובץ בנפרד, או שמירה ישירה לתיקייה.

**האתר:** https://nmishaly.github.io/jpgtopng/

נבנה על ידי Netzer Mishaly.

## עקרונות

- **ללא שמירה בשרת** – ההמרה מתבצעת כולה בדפדפן. הקבצים לא נשלחים לשום מקום, ומדיניות ה-CSP של הדף (`connect-src 'none'`) חוסמת טכנית כל שליחת נתונים. האתר עובד גם בלי חיבור לאינטרנט אחרי הביקור הראשון.
- **שמירה על איכות** – כל תמונה מפוענחת פעם אחת ונכתבת ב-PNG, פורמט ללא אובדן. הבדיקות האוטומטיות מוודאות שהפיקסלים זהים לחלוטין למקור (הפרש 0).
  - **צבע רחב (Display P3)** – תמונות טלפון בטווח צבעים רחב נשמרות ב-P3 עם פרופיל צבע מוטמע, במקום להיחתך ל-sRGB.
  - **כיוון התמונה** לפי EXIF מוחל על הפיקסלים.
  - **נתוני תמונה (EXIF)** – תאריך, מצלמה ומיקום GPS נמחקים כברירת מחדל (פרטיות); אפשר לבחור לשמור אותם.
  - **רזולוציית הדפסה (DPI)** נשמרת.
- **קבצים קטנים יותר** – מקודד PNG ייעודי: ללא ערוץ שקיפות מיותר (JPG אינו שקוף), PNG אפור לתמונות שחור-לבן, ובחירת מסנן לכל שורה. התוצאה קטנה בכ-20% מה-PNG שהדפדפן מייצר, ללא שינוי בפיקסל אחד. אפשר גם לבחור פלט **WebP ללא אובדן** (קטן יותר), בדפדפנים שבהם נבדק שהוא באמת ללא אובדן.
- **כמויות גדולות** – ההמרה רצה במקביל ב-Web Workers. תמונות מעובדות ברצועות, כך שגם תמונות של 48 מגה-פיקסל עובדות (כולל ב-Safari באייפון, שמגביל את גודל ה-canvas). ב-Chrome/Edge אפשר לשמור ישירות לתיקייה – כל קובץ נכתב לדיסק ומשתחרר מהזיכרון. קובצי ZIP מעל 4GB נכתבים בפורמט ZIP64.

## שימוש

- גרירת קבצים או **תיקייה שלמה** (כולל תת-תיקיות), בחירה בלחצן, או הדבקה (Ctrl+V).
- תצוגה מקדימה, גודל לפני ואחרי, הסרת קובץ בודד ועצירת התור.

## הרצה ופיתוח

```bash
npm start                # http://localhost:3000  (PORT=8080 npm start לפורט אחר)
npm test                 # בדיקות יחידה (מקודד PNG, ZIP, קריאת JPEG/HEIC)
npm run test:e2e         # בדיקות דפדפן (Playwright: Chromium, Firefox, WebKit)
npm run build:artifact   # בניית גרסת הקישור המשותף ל-dist/artifact/
```

בדיקת ה-HEIC בדפדפן משתמשת בתמונה לדוגמה של פרויקט libheif, שמורדת ב-CI:
`curl -fsSL -o e2e/fixtures/example.heic https://raw.githubusercontent.com/strukturag/libheif/master/examples/example.heic`

## פרסום

כל דחיפה לענף הראשי מריצה את כל הבדיקות (יחידה + שלושה דפדפנים), ורק אם הן עוברות – מפרסמת ל-GitHub Pages (`.github/workflows/pages.yml`).

גרסה נוספת מפורסמת ב-claude.ai: https://claude.ai/artifact/XxQLG8hqQPRcPJfCUUp3kA (בונים עם `npm run build:artifact` ומפרסמים מחדש את `dist/artifact/`).

## מבנה

| קובץ | תפקיד |
|---|---|
| `public/index.html`, `style.css` | ממשק (עברית, RTL, מצב כהה) |
| `public/app.js` | קליטת קבצים (בחירה, תיקייה, גרירה, הדבקה), תור והמרה במקביל, הורדות, שמירה לתיקייה |
| `public/convert.js` | צינור ההמרה: פענוח, צבע רחב, רצועות, PNG/WebP, תמונה מוקטנת |
| `public/png.js` | מקודד PNG זורם (מסננים, דחיסה, iCCP/eXIf/pHYs) |
| `public/jpeg-meta.js` | קריאת נתוני JPEG: פרופיל צבע, EXIF, DPI, אפור/צבע |
| `public/icc.js` | פרופיל הצבע Display P3 שמוטמע ב-PNG |
| `public/heic.js` | פענוח HEIC (מובנה ב-Safari, אחרת libheif ב-WebAssembly שנטען רק לפי הצורך) |
| `public/webp.js` | בדיקה שה-WebP של הדפדפן באמת ללא אובדן |
| `public/zip.js` | יצירת ZIP / ZIP64 ו-CRC32 |
| `public/sw.js`, `manifest.webmanifest`, `icons/` | עבודה ללא חיבור והתקנה כאפליקציה |
| `public/vendor/libheif/` | ספריית libheif (LGPL-3.0, ללא שינוי) |
| `server.js` | שרת סטטי מינימלי עם כותרות אבטחה, ללא נקודת העלאה |
| `test/`, `e2e/` | בדיקות יחידה ובדיקות דפדפן |
